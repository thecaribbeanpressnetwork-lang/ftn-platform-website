Method

Selection is production.

More output does not equal more value. The real leverage is a disciplined filter that protects the song, the artist and the audience.

1 · Define

Start with the emotional job, cultural context and musical objective.

2 · Generate / build

Create options, parts, arrangements and visual directions without confusing quantity with quality.

3 · Reject / refine

Remove weak phrasing, fake-feeling vocals, gimmicks, bad images and anything that breaks character.

4 · Finish

Mix, master, QC, package, document and release with ownership and provenance intact.

“If the groove wrong, I reject it. If the voice feels fake, I fix it. If the song doesn't feel like home, it doesn't leave the room.”
