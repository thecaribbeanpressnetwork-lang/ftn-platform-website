FTN Glossary

Words should not outrun reality.

The operational meaning of the labels used across FTN.

LIVE

A functioning public journey whose critical production acceptance checks have passed. It does not mean every future capability exists.

AVAILABLE

A functioning public journey with visible limitations and failure states. AVAILABLE is not permission for decorative controls.

PRIVATE

Not available to the public. Access requires server-side authorization; knowing a route is never authorization.

VAULTED

Retained in FTN ownership but excluded from public discovery until a separate release, safety and governance gate passes.

Official source

A record or page controlled by the named authority. Linking to it does not imply an FTN partnership or endorsement.

FTN context

FTN-authored explanation or analysis kept distinct from the underlying source record.

Draft / generated preview

Work that has not been approved or published. A generated result is never described as completed merely because an interface displayed it.

Submitted transaction

A protected server receipt with a transaction ID. A browser-local draft or prepared email is not a submission.

Local save

Data stored in the current browser. It is not synchronized, recoverable by FTN or a cloud backup unless the product says otherwise.

Authorized embed

Media played through a source/provider interface permitted for that use. It does not grant download, remix or redistribution rights.

Deterministic routing

Transparent rules match words to FTN products. It is not a generative model and is not presented as one.

Owner

A server-assigned least-privilege role bound to an immutable user ID. An email, link, browser flag or editable profile cannot create it.
