FTN STATISTICS · VERIFIED OFFICIAL DATA

Real numbers. Real sources. Every time.

FTN Statistics is the shared, source-verified data foundation behind FTN Live, ibis.ai and the rest of the platform -- one place where a Trinidad and Tobago official statistic is checked, dated and attributed once, then reused everywhere it belongs, instead of copied and re-guessed on every page.

HOW THIS WORKS

Verified, not duplicated.

Every figure below is sourced from a real, named, linked Trinidad and Tobago government publisher -- the Trinidad and Tobago Police Service's own published Statistical Reports Collection for the current year, and the Central Statistical Office's compiled historical workbook for 2015–2024. FTN does not estimate, interpolate or manufacture a number where a verified one is not available -- when a source doesn't publish a reference date, FTN says so explicitly rather than implying the figure is current.

"Reported" means reported to police -- it is not the same thing as confirmed, prosecuted, or the full, true extent of an issue. Historical and current-year figures use different source publications and are always shown as two distinct series, never blended into one continuous "current" line.

What FTN Statistics is not

  • Not a Community Connect civic-report count -- those are FTN's own collected reports, a separate, differently-labelled layer with its own confidence, never combined with official government figures here.
  • Not a live daily counter -- a historical annual total is never presented as today's condition, and a current-year cumulative total is never described as "as of right now" beyond FTN's own last verified check.
  • Not a redistribution of the underlying government dataset file -- FTN cites and links the real published figures; it does not host or resell the source's own compiled workbook.
CONNECTED ACROSS FTN

The same verified data, everywhere it belongs.

This is not a second, isolated copy of the numbers above -- FTN Live's Observer Console renders the identical data/crime-statistics.json record through the same shared component, and ibis.ai's indicator analysis can be extended to read the same js/ftn-statistics.js contract, so a future question ibis answers about this data carries the same real source, reference date and confidence -- never a re-guessed number.
