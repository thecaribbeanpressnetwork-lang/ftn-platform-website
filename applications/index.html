Capabilities

These used to be separate FTN products. Each one's real, reusable logic now runs as a genuine capability of the product named below -- nothing was deleted, and every legacy route still works.

Scenario Workspace

CAPABILITY

Its calculators/comparison/evidence-view logic overlaps ibis's own EBR, Butterfly, Correlation and Prediction reasoning engines -- a capability of ibis, not a second, parallel evidence/scenario product.

Use inside FTN ibis →Legacy route

Parliament

CAPABILITY

A specialized civic vertical inside FTN Govern -- official source directory, record lookup and broken-source reporting for Parliament specifically, not a second, independent civic product.

Use inside FTN Govern →Legacy route

TV

CAPABILITY

Scheduled/on-demand programme guide, a capability of FTN Screen — not a current-conditions or Live product.

Use inside FTN Screen →Legacy route

Screen — Display Mode

CAPABILITY

Glanceable, no-account, kiosk/full-screen ambient view for a shared physical screen -- a capability of FTN Screen, not a standalone product.

Use inside FTN Screen →Legacy route

Learn

CAPABILITY

AI tutoring/explanation/study guidance belongs in ibis; the real FTN Skills/FTN School provider-discovery listing function is preserved and stays queryable through ibis, not deleted.

Use inside FTN ibis →Legacy route

Riddim

CAPABILITY

Its real music-creation engines (Fire, DAW, EPK) now run as genuine ibis capabilities; this page remains live as a legacy hub/handoff into ibis and FTN DJ Tube's specialized performance interface, not a second, independent music product.

Use inside FTN ibis →Legacy route

Fire

CAPABILITY

Its pure Caribbean rhythm/bass/harmony/melody generator is now a shared, headless music engine (js/ibis-caribbean-music-engine.js) that ibis calls directly for on-device instrumental generation -- a capability, not a separate product to route to.

Use inside FTN ibis →Legacy route

Kaiso

CAPABILITY

Kaiso is FTN Live's source-backed current-affairs/news desk -- a real editorial identity and mode of FTN Live, not a second, independent current-information product.

Use inside FTN Live →Legacy route

DAW

CAPABILITY

Its WebAudio DSP chain (EQ, shelves, cuts, gain, tempo, spectrum, WAV/MP3 export) is now a shared, headless audio engine (js/ftn-audio-dsp-engine.js) -- ibis calls it directly for AUDIO_PROCESSING, and FTN DJ Tube or a future media tool can call the exact same engine rather than a copy.

Use inside FTN ibis →Legacy route

EPK

CAPABILITY

Its creator-metadata/credits/press-links schema is now a shared module (js/ftn-epk-schema.js) that ibis uses directly for the EPK_GENERATION capability; the existing preparation workspace on the Radio page keeps working unchanged.

Use inside FTN ibis →Legacy route

Picks

CAPABILITY

FTN Invest-in’s supporting recommendation capability with free-first guidance and explicit affiliate, support and editorial relationship labels.

Use inside FTN Invest-in →Legacy route
