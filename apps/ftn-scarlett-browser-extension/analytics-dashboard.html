Scarlett — local analytics

This browser profile only. Not connected to any backend.

What this actually is: every row below comes from events logged locally to chrome.storage.local on this device, in this browser profile, while you used Scarlett. Nothing here has ever left your browser. This page exists to prove the event schema is real and populated correctly -- it is not a founder dashboard aggregating real users. Wiring these events to an actual backend so a founder could see real, cross-user adoption is a separate, deliberate decision (see the V2 analytics privacy model doc) that has not been made. Event content is deliberately narrow: mode names, category labels, counts and booleans only -- never a URL, page title, search query or any identifier.
