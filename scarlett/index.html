FTN SCARLETT · ADAPTIVE INTERFACE LAYER

The web adapts to you. Not the other way around.

Scarlett is a browser extension that changes how an existing site is presented and interacted with — based on what kind of page it is, what you're trying to do, and how sensitive it is. It's not an AI sidebar, a page summarizer or a site skin. Original is always one click away.

The mode continuum

Six intervention levels, from doing nothing to fully rebuilding the page's presentation — you choose how far Scarlett goes, and it never goes further than the page's own sensitivity allows.

Original

The untouched source page. Always one click away.

Available

Assist

Native interface stays primary; Scarlett adds a contextual panel, accessibility help and an ibis handoff.

Available

Adapt

Improves hierarchy and reduces clutter while preserving the source's own identity and controls.

Available

Transform

Rebuilds the page as a task-focused deck — grounded only in real page content, never invented.

Available

Compare

A draggable reveal between the original page and Scarlett's presentation of it.

Available

Blend

A staged 0–100% slider between Original and full Transform, six fixed stops.

Available

On sensitive surfaces (banking, payment, health, identity, government sign-in) and inside Google Docs/Sheets/Gmail/Calendar, Scarlett automatically stays in Assist — Adapt, Transform and deep Blend levels are not offered there, to protect muscle memory and avoid touching anything consequential.

Data Faucet — see who a page talks to

Turn on Data Faucet Protection and Scarlett shows you the real, observed third-party connections a page makes — analytics, advertising, social pixels, and unknown hosts — categorized from a disclosed, curated domain list. It's never presented as complete tracker coverage, because no such claim would be honest.

  • Real blocking of known trackers, never payment/CDN/font infrastructure (so it can't silently break checkout or a site's layout)
  • "Site broken?" adds a one-click local exception if Shield ever breaks something
  • Entirely opt-in — a separate permission, requested only when you turn it on, removable in one click

Search with Scarlett · Find with Scarlett

Search

A short query, source-backed results from FTN's own reviewed intelligence registry — the exact same canonical endpoint FTN's own ibis browser companion already uses.

Find

Describe an objective instead of typing keywords ("find me a grant I could apply for") and Scarlett adapts how results are presented to what you're actually trying to do.

Limited

Find's retrieval today uses the same source-backed search FTN ibis already exposes, with the presentation adapted to your objective — it is not yet a separate multi-step research pipeline. Only ever sent on explicit submit; your query text is never logged by Scarlett's own analytics.

How Scarlett, ibis and Headspace fit together

ScarlettAdapts how the page in front of you looks and behaves
ibisReasons: evidence, provenance, governed action
HeadspaceThe workspace a complex task unfolds inside

Scarlett never becomes a second intelligence brain — it doesn't call any AI model itself. "Ask ibis about this page" and "Open in Headspace" are explicit, reviewed handoffs: you see exactly what would be sent before anything leaves your browser, and nothing is ever sent automatically.

Privacy model

Local by default

Page analysis, risk classification, Site DNA, the transformation ledger and your accessibility preferences never leave your device.

Data Faucet

Reads request destinations on the current tab only, once Shield is on. Never inspects request/response bodies.

ibis / Headspace handoff

A single reviewed package — page type, your typed intent, selected text or a short summary — sent only after you click Insert.

Search / Find

Only the text you typed, sent to FTN's own ibis endpoint on explicit submit. No page content, no identifiers.

Analytics

Local-only event log (mode used, feature adopted) with a structural filter against anything resembling page content. No real-user backend is wired yet.

Billing

WAM's hosted checkout receives payment details directly — FTN and Scarlett never see card, CVV or wallet credentials.

Supported browsers & installation

Chrome Edge Opera Firefox — not yet ported (Manifest V3 differences)

Not yet published to the Chrome Web Store. Until then, install the developer build directly:

  1. Download the latest release ZIP from FTN's GitHub releases and unzip it.
  2. Open chrome://extensions (or the equivalent Edge/Opera page) and turn on Developer mode.
  3. Click "Load unpacked" and select the unzipped Scarlett folder.
  4. Pin Scarlett's icon to your toolbar and open any normal web page to start.

See it on your own page

Install Scarlett, open any article or listing page, and try Assist → Adapt → Transform → Original. It takes under a minute.
