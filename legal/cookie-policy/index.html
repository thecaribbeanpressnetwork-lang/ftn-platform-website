Cookie Policy

Effective date: July 12, 2026 · Operator: RealityArtTV Media, operating the FTN Platform · Governing jurisdiction: Republic of Trinidad and Tobago

Current Position Local Browser Storage Third-Party Resources Browser Controls Future Use Updates Contact

Current Position

The FTN website code does not currently set an FTN advertising or analytics cookie. FTN Account uses Supabase Auth session material in browser storage. Cloudflare or another infrastructure provider may set strictly necessary security cookies while delivering or protecting the site.

The website does not currently use:

  • behavioural advertising cookies;
  • cross-site tracking cookies;
  • FTN behavioural-analytics cookies;
  • social-media tracking pixels;
  • an FTN password cookie;
  • payment cookies.

Local Browser Storage

The website uses local browser storage for interface preferences, explicit local work and—when a user signs in—Supabase Auth session material.

These settings may include:

  • Presentation Mode or Live Mode;
  • the floating Presentation Mode control position;
  • whether the control was dismissed during a page view;
  • country preference, last public task, saved pages and source watchlists;
  • clearly labelled drafts, recent items and creative project recipes;
  • authentication session tokens needed to keep a signed-in user on the current device.

Local drafts and preferences normally remain on the visitor’s device. Authentication tokens are transmitted to Supabase Auth and protected FTN functions when needed to authenticate an action. Clearing browser storage signs the user out and removes local work that was not exported or cloud-saved.

Third-Party Resources

The website currently requests font resources from Google Fonts, authentication code from the pinned Supabase JavaScript distribution when FTN Account is used, Cloudflare Turnstile for protected forms, and Cloudflare Web Analytics/delivery telemetry on the production host.

That request is made by the visitor’s browser to the third-party provider and may involve ordinary technical request information.

The third party’s own terms and privacy practices govern its processing.

Browser Controls

Visitors can clear local storage, restrict third-party resources or change privacy settings through their browser.

Clearing local storage may reset interface preferences.

Future Use

FTN may introduce cookies or similar technologies in the future for legitimate purposes such as:

  • security;
  • authentication;
  • accessibility;
  • consent management;
  • analytics;
  • service delivery.

Where required, FTN will provide appropriate notice and choice before or when such technologies are introduced.

Updates

This policy will be updated when the website’s use of cookies, analytics or browser storage changes.

Contact

Questions about this Cookie Policy may be submitted through the General Enquiries pathway on the FTN Contact page.
