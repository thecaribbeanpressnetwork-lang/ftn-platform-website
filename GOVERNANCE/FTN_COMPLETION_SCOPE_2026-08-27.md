# FTN completion scope — 2026-08-27

This record distinguishes active deployable modules from prior concepts so FTN does not accumulate phantom technical debt or restart speculative builds without Nexus evidence.

## Active completion targets

- **Mayor Mode / Nexus Command** — active, protected production surfaces. Complete through shared scoped municipal records, audit history, verified Scout intelligence, evidence and controlled access.
- **ibis-ai intelligence infrastructure** — active. Provenance/evidence/live/statistical routing already exists; institutional memory is explicit, structured, founder-controlled and audited. Raw chats are not automatically ingested into institutional memory.
- **FTN Scout 2.0 / Money Scout** — active. Zero-LLM official-source discovery + founder-reviewed current intelligence + Nexus/Opportunities/Mayor distribution. Scout cannot spend, submit applications, accept contracts or create products automatically.
- **FTN Screen Festival & Market Scout** — active Screen extension. Uses a verified festival registry and deterministic eligibility/deadline/premiere/package checks. The festival remains the authority; unknown rules fail to REVIEW rather than being inferred.

## HOLD — not active deployable Product Registry obligations

The following ideas were discussed in earlier workstreams but no deployable module/source implementation exists in the current authoritative FTN repositories as of this audit:

- Music Video Studio
- LTX provider chain
- Creator Marketplace / MyLead marketplace integration
- FTN Moat as a separate product

These are **HOLD**, not broken production modules. They may only return to BUILD/EXTEND after Scout/Nexus reconnaissance identifies a compelling user/business/institutional case and the founder approves promotion into the Product Registry. Existing FTN media, Screen, Opportunities, Scout and Nexus infrastructure should be extended before creating another standalone product.

## External actions that code cannot truthfully close

- Public Android store publication requires the relevant store account, listing, signing/release action and any platform review.
- Municipal/agency data agreements, procurement submissions, grant applications and partner outreach require authorized external institutional action.
- FTN code may prepare evidence and readiness material but must not represent these actions as completed until verified externally.
