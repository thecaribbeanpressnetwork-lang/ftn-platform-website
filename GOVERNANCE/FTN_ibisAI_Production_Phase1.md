# ibis.ai — Production Phase 1

## Purpose
Turn ibis.ai into a truthful, useful FTN intelligence-routing workspace now while preserving a clean path toward future Caribbean data, model and decision-support capabilities.

## Operational now
- Goal-to-product routing through the FTN Intent Router.
- Ranked product recommendations from the FTN Product Registry.
- Visible explanations for why each product matched.
- Country-context display using FTN's existing country preference.
- Curated example goals across Community Connect, Opportunities, Riddim, Events, Observatory and Kaiso.
- Browser-local recent-goal history with reuse and clear controls.

## Not yet operational
- Open-ended conversational AI.
- Autonomous access to government or private databases.
- Legal, medical or government-decision conclusions.
- Predictive scoring of citizens, communities or institutions.
- Live regional data synthesis beyond sources explicitly connected elsewhere in FTN.

## Architecture
The current layer is deterministic and explainable. The Intent Router and Product Registry remain the source of truth for current routing. Future language models, retrieval systems and structured Caribbean data services should attach behind the same user-facing goal surface instead of replacing it with a separate product.

Any future model integration must preserve auditability, product-route explanations, data minimization, source provenance and human-visible trust boundaries.

## FTN Product Mnemonic Layer
ibis.ai uses a decision-network mnemonic: a luminous intelligence core, radial routes, orbit structure and endpoint nodes. It represents ibis.ai receiving a goal, evaluating possible paths and routing the user into the wider FTN ecosystem.

The mnemonic is behaviorally connected to the product. It pulses when ibis.ai executes a routing action, reinforcing the relationship between user intent, evaluation and destination. It remains decorative and non-blocking, and all motion is disabled for users who prefer reduced motion.

The visual is intentionally distinct from Face The Nation's broadcast-signal mnemonic. ibis.ai uses its established purple intelligence accent on the shared FTN black foundation so each product becomes recognizable without fragmenting the master brand.
