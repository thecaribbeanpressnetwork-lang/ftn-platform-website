# FTN Mayor Mode — Canonicalization Record

Date: 2026-08-27
Status: Founder-directed consolidation

## One product rule

FTN has one Mayor Mode product. Do not create additional Mayor Mode products, forks, dashboards or simulated public clones.

## Canonical sources during completion

- **Mayor Mode Version 10** (`https://ftn-mayor-mode.bossbeats3.chatgpt.site/`) is the founder-designated cumulative UX / presentation reference. It contains the broadest approved interaction and municipal-intelligence concept set.
- **`/mayor-dashboard/` in this repository** is the FTN-owned operational kernel. It already uses FTN Account authentication, protected Mayor access, real Community Connect data, privacy-generalized map coordinates, synchronized filters, source-dated national context and deterministic brief generation.
- The old public **`/mayor-preview/` simulated page is retired as an independent surface** and redirects to `/mayor-dashboard/`.

The completion objective is to bring the strongest approved Version 10 experience into the FTN-owned operational kernel without replacing real data with simulation or creating another fork.

## Truth boundary

Production Mayor Mode must distinguish clearly between:

1. live FTN / Community Connect observations;
2. authoritative external source data;
3. historical official baselines;
4. calculations and projections;
5. scenarios / forecasts;
6. demonstration-only examples.

Never present demonstration data, manually authored opportunity scores, scenarios, estimates or generated reports as live municipal facts.

## Near-term completion gate

The next Mayor Mode release should prioritize:

- canonical FTN / ibis-ai branding;
- one synchronized map-first operating experience;
- every visible control functional or removed;
- real server-enforced access and a safe read-only councillor presentation pathway;
- Community Connect ingestion through the shared production database;
- evidence/source/methodology visibility;
- responsive desktop, mobile and projector behavior;
- a frozen councillor presentation release;
- no duplicate Mayor Mode public routes.

## Architecture rule

Mayor Mode is a scoped municipal operating view over shared FTN infrastructure. It should reuse Community Connect, FTN Statistics, FTN Live, ibis-ai, shared identity/access, shared evidence/provenance and Nexus governance rather than duplicating them.

Mission Control / Nexus Command remain broader institutional/founder control layers and must not become parallel copies of Mayor Mode.

## Deferred expansion

Do not add speculative new Mayor Mode modules during the completion sprint. Product/module expansion resumes only after Scout / Money Scout competitive, funding and opportunity reconnaissance has been rebuilt and run.
