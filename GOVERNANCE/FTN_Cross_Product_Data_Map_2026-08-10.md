# FTN cross-product data and permission map

| Producer | Consumer | Data allowed | Gate | Explicitly prohibited |
|---|---|---|---|---|
| Product Registry | Navigation, directory, sitemap, Account, ibis router, God Mode | Public product identity, hierarchy, accurate status and routes | Git review; public/private flag | Private Love/God Mode discovery or false LIVE status. |
| Community Connect | Website and Mission Control | Approved public handoff/aggregate only | Separate protected app interface | Private reports, evidence, reporters, unrestricted joins. |
| Parliament / public sources | Mission Control, Face The Nation, Invest, Events, Opportunities | Dated public source metadata and canonical source link | Source registry, provenance and last-checked date | Government endorsement, fabricated current state or unreviewed inference. |
| Events / Screen / TV / Live / Radio | Shared media discovery | Authorized embed/reference metadata, owner/channel, schedule/source status | Provider/source terms and user-initiated playback | Downloading, ripping, restreaming or claiming FTN ownership. |
| Kaiso / Riddim | Public music discovery | Artist/title/source/credit and culture context | Source/rights labels | Treating playback as remix/download permission. |
| FTN Fire | DAW / ibis | User-selected instrumental recipe, locally generated WAV/stems metadata | Explicit user handoff; local files | Lyrics, cloned artists, secret upload or paid provider call. |
| DAW / DJ local mode | User project export | User-owned audio buffers in memory and provider-neutral recipes | Rights declaration; browser limits | Automatic upload, streamed-media extraction or server-storage claim. |
| ibis Creative Studio | Approved provider adapter | Minimum project brief needed for the selected job | Verified account, explicit transfer, approved provider, quoted cost, credits, global/provider switches | Consumer-login automation, secrets in browser, surprise charges or unapproved provider. |
| Account | Product saves/preferences | User-owned preferences and saved item references | Supabase Auth + own-row RLS | Role grants from client metadata or cross-user access. |
| FTN Love | Love control service only | Private profile, interests, mutual matches, messages, blocks/reports | 18+, explicit consent, Auth, RLS, server mutual-match logic | Ads, public intelligence, civic profiling, indiscriminate message surveillance or public discovery. |
| Protected submissions | Founder moderation queue | Minimum contact, authority/consent, structured submission, transaction receipt | Auth where required, Turnstile, server validation/rate limits | Automatic publication, guaranteed coverage/placement or fake success. |
| God Mode | Owner | Operational aggregates, audit, costs, controls, privacy/safety queues | Immutable owner ID, server authorization, MFA/reauth staging proof | Client-side role claims, public discovery, direct evidence deletion. |

Private ibis, Love, Account and Community Connect data are never combined into public intelligence or advertising by default.
