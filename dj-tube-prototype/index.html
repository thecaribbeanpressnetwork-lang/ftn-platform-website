DJ DROP BANK · DJ-OWNED AUDIO

DJ-owned drops only. The production engine will align a selected drop to a beat/phrase, duck the music, fire the drop, then restore the mix.

CARIBBEAN MUSIC DISCOVERY BOT

Discovery can use relevant DJ-mix playlists as track-list leads only: read public playlist/title metadata, extract candidate track names, then search for the individual official/artist/label upload. The DJ mix itself is never downloaded, indexed as a track, or used as the playback source. Titles containing the standalone word mix are excluded; remix is allowed.

CONTENT & PLAYBACK BOUNDARIES

YouTube remains the playback/display source. DJ Tube does not download or rehost YouTube audio.

Automatic ad skipping is not implemented. We can locate the music start after permitted playback and set the cue point.

True independent headphone monitoring of YouTube iframe audio requires a permitted audio source exposed to the Web Audio engine; the UI is ready for that architecture.

DJ-owned files can use the full audio engine: cue, EQ, tempo, loops, drops, crossfade and headphone routing.
