PURPOSE

This Asset Library is the authoritative visual reference for the FTN
Platform ecosystem.

These Asset Extraction Boards (AEB) are engineering documents for
AI-assisted asset extraction, optimization, organization and production.

They define: - Brand Identity - Website Design - Product Graphics -
Marketing - Mission Control - UI Components - Photography Direction -
Website Architecture - Production Roadmap

CURRENT PROJECT

Build the FTN Platform Website.

The website is completely separate from the Community Connect
application.

Do NOT: - Modify Community Connect source code. - Move files inside the
Community Connect application. - Rename application assets.

Shared assets should be copied from this library.

EXTRACTION RULES

Extract assets individually. Generate SVG, PNG, WEBP and AVIF where
appropriate. Maintain proportions and colours. Use sRGB. Optimize for
web. Generate transparent backgrounds.
